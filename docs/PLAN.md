# 開發規劃

## 目標

一個瀏覽器形式的簡易 2D 平面設計工具，以「線性流程」引導設計：先定構圖，再定視覺動線，再切區塊，最後才放物件與微調。

- 任何人 clone 後雙擊 `GraphicDesigner.html` 即可使用，或直接開 GitHub Pages
- 高度模組化：每一層、每個版型、每組超參數都是獨立檔案，新增時不需要修改既有程式

## 技術選型

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 | TypeScript | 型別檢查讓模組介面明確 |
| 建置 | Vite + vite-plugin-singlefile | 輸出單一 HTML，雙擊即可開啟（file:// 不支援多檔 ES module） |
| UI | Svelte 5 | 輕量、樣板少 |
| 繪圖 | Konva.js | 內建 Layer 概念與物件變形控制點 |
| 匯出 | PNG（Konva）、PDF（jsPDF）；專案檔 .json 可再次開啟繼續編輯 | 皆可在瀏覽器端完成，不需後端 |

## 核心設計

- **幾何與渲染分離**：版型的 `generate()` 是純函式，只輸出圖元與錨點
- **方向變換由核心負責**：0/90/180/270° 旋轉加上水平／垂直翻轉。旋轉 90° 時以長寬對調的畫框生成，保證貼合畫布
- **錨點**：每個版型輸出關鍵點（交點、螺旋中心…），第三、四層會吸附到這些錨點
- **參數面板自動生成**：依據 `params.json`
- **單一專案狀態**：`core/store.svelte.ts`，之後序列化成 JSON 即為存檔

## 已確認的決定

- 畫布預設：A4、A5、B4／B5（JIS）、DM、名片（台灣 90×54 與日規 91×55 兩種都提供）、16:9、4:3、1:1、4:5、9:16
- 匯出：PNG、PDF。**不做 PPT**（2026-09-27 決定）
- 專案存成 .json 專案檔，側欄「專案檔」區域可拖放或點選開啟，繼續上次的編輯
- 構圖引導線：藍色（主線）／綠色（輔助線）／紫色（錨點）虛線，於 `config/theme.json` 設定
- 第四層加入「文字」物件
- 字型：中文 19 種、英文 32 種，皆為 OFL 可商用；**字型檔不進 repo**，執行時從 Google Fonts 載入（見 docs/FONTS.md）

## 已知限制

- PDF 內容是高解析度影像（非向量），文字無法在 PDF 中選取或編輯
- 多選拖曳時不吸附（單選時才吸附）

- 控制點吸附到錨點後，存的是相對位置（0–1）。之後改畫布尺寸或換構圖，控制點不會跟著錨點移動。若需要「綁定在錨點上」，可在之後加入
- 第二層引導目前各自獨立，不會讀取第一層構圖的資料（只在拖曳時吸附）
- 區塊只吸附水平與垂直的線（以及錨點），斜線與曲線不吸附
- 文字沿曲線排列（例如沿著黃金螺旋）尚未支援

## 里程碑

- [x] **M1**：畫布預設、第一層 10 種構圖、旋轉翻轉、參數面板、步驟條、圖層顯示切換、匯出 PNG
- [x] 字型庫：中英文字型清單、按需載入、預覽（第四層文字物件會使用）
- [x] **M2**：第二層視覺引導 8 種（一點透視、兩點／三點透視、景深分帶、Z 型、F 型、古騰堡圖表、自訂視線路徑、集中線），可疊加多條；畫布上可拖曳控制點並吸附構圖錨點；存檔／讀檔 JSON、自動暫存、復原／重做
- [x] **M3**：第三層區塊
  - 手動新增：在畫布空白處拖曳畫出、或按「新增區塊」；拖曳、縮放、方向鍵微調時吸附到構圖線、錨點與畫布中線
  - 區塊用途（主視覺、標題、內文、圖片、行動呼籲、Logo、背景、留白）、名稱、填色／只有框線、顏色、不透明度、疊放順序、複製、刪除
  - 建議區塊：由各構圖與引導版型提供（例如三分法的欄列、黃金螺旋的大正方形與副區、古騰堡四區、Z 型轉折點），加上以錨點為中心的主體區塊；滑鼠指到即預覽，點一下採用
  - 檢視工具列：隨時切換構圖線、錨點、視覺引導、區塊的顯示；⌘; 一鍵切換全部輔助線
  - 黃金螺旋可調大小與位置（以畫布為準，翻轉後位置不變）
- [x] **M4**：第四層物件
  - 物件種類（各自一個模組）：文字、圖片、矩形（圓角）、圓形、三角形、多邊形、星形、線條
  - 放置：畫布中央、放進區塊（物件框 = 區塊，圖片自動裁切填滿）、以錨點為中心；已放置的物件也能「放進區塊」「移到錨點」
  - 拖曳、縮放、旋轉（45° 吸附）；拖曳時吸附到構圖線、錨點、區塊邊與中線
  - 文字：字型庫 51 種字型、字級（mm 畫布用 pt）、字重、對齊、行高、字距；畫布上雙擊文字即可編輯
  - 背景：顏色、背景圖（填滿／完整／拉伸、不透明度）
  - 圖片存在瀏覽器 IndexedDB；下載的專案檔會把用到的圖片一起打包；過大的圖片縮到長邊 4096px
  - 匯出 PNG 只輸出作品（背景＋物件），不含引導線與區塊
  - 檢視工具列可切換「輔助線在物件上層／下層」與輔助線不透明度，方便確認物件是否對齊錨點
  - 所有物件都能拖曳控制點縮放；文字拖四個角連字級一起縮放，拖邊只改文字框寬高
  - 側欄「專案檔」區域：拖放或點選 .json 專案檔即可繼續編輯；⌘S 儲存
- [x] **M5**：第五層微調與匯出
  - 多選：Shift 點選、在空白處拖曳框選、⌘A 全選；多選可一起拖曳、縮放、刪除、複製、方向鍵微調
  - 對齊（靠左／水平置中／靠右／靠上／垂直置中／靠下），基準可選「選取範圍」或「畫布」；水平／垂直等距分佈；統一不透明度
  - 匯出 PNG：mm 畫布選 150／300／600 dpi，px 畫布選 1×／2×／3×
  - 匯出 PDF：頁面等於畫布實際尺寸；mm 畫布可設出血與裁切標記（內容為高解析影像）
  - 改畫布尺寸時物件等比例調整，不會被拉伸變形

- [x] **M6**：依參考範例補強通用性
  - 多構圖與套用範圍（構圖裡再套構圖，例如雙黃金螺旋），區域連動
  - 區塊形狀：橢圓、多邊形；照片可用區塊形狀裁切；線條切出的區域可作為建議區塊
  - 圖片焦點：拖曳 ⊕ 讓照片主體對準錨點（圖片與背景）
  - 吸附：斜線與曲線、旋轉角度對齊引導線、尺寸比例（0.618、1/3…）
  - 直排文字（直排標點、縱中橫）
  - 三角形三頂點＋金字塔分層、斜帶構圖、自訂引導線
  - 版型範例 32 個（src/recipes），一鍵套用構圖＋區塊
